## Description

**The Legend of the Cat & Dog is a game inspired by 2D platformers that emphasizes teamwork as a way to progress through the game.**

  * **Goal:** Have fun and create a cooperative platformer game that requires teamwork and puzzle-solving.
  * **Uniqueness:** Two distinct characters—a cat and a dog—with complementary abilities.
  * **Design Motivation:** Encourage collaboration in both multiplayer and solo modes through level-specific challenges.

---

## 🎮 Controls

**Keyboard:**

* **Activate Character -** Enter
* **Move -** A / D
* **Jump -** Space
* **Sprint -** Left Shift
*  **Attack/Bark -** B
* **Dig -** E
* **Swing -** Ctrl
* **Switch Characters -** Q

**Controller:**

* **Activate Character -** Start
* **Move -** Left Stick / D-Pad
* **Jump -** Button South
* **Sprint -** Left Trigger
*  **Attack/Bark -** Button East
* **Dig -** Button West
* **Swing -** Right Trigger
* **Switch Characters -** Button North

## How To Play

1. Clone the repo: 'git clone https://github.com/hrithiksandhir/manhattan-university-capstone-project'
2. Open Unity Hub and click **Add**
3. Select the cloned project folder
4. Open the main scene in **Assets/Scenes**
5. Hit **Play**
